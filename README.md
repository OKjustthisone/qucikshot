# QuickShot

QuickShot 是一款基于 WPF (.NET Framework 4.8) 开发的轻量级、常驻后台的 Windows 截图与标注工具。界面深度遵循 **Windows 11 Fluent Design（浅色主题）** 设计规范，提供极致流畅的截图、批注与贴图体验。

---

## ✨ 核心特性

- **🔔 背景常驻与托盘服务**：
  - 关闭主界面时自动最小化至 Windows 系统托盘，不会退出程序，保证截图随时可用。
  - 支持右键托盘图标呼出快捷菜单（显示、截图、设置、退出）。
  - 支持 **随 Windows 开机自启**，自启时自动静默运行于托盘后台。

- **⌨️ 多截图模式与独立全局快捷键**：
  - 提供三种截图方式，并支持在设置中为每种模式独立设置/捕捉全局物理快捷键：
    - **区域截图**（默认 `Ctrl + Alt + A`）
    - **窗口截图**（自动捕捉当前活动窗体，默认 `Ctrl + Alt + W`）
    - **全屏截图**（捕捉整个屏幕，默认 `Ctrl + Alt + F`）
  - 全局快捷键注册带占用冲突检测，设置完毕立即重载生效。

- **🎨 现代标注编辑器**：
  - 界面采用优雅的圆角卡片、毛玻璃质感与 HSL 调色板设计，色块按钮边缘有精致灰色边线以防白色色块与浅色背景混淆。
  - **基础工具**：支持绘制矩形、椭圆、箭头、直线、画笔。
  - **文本标注**：一键添加文本框输入文字，默认字号可由设置全局自定义。
  - **打码模糊**：内置像素化马赛克与高斯模糊画笔，打码强度可由设置自定义。
  - **高级二次编辑**：无需切换工具，鼠标单击已添加的任何图形元素即可直接选中，支持拖拽移动、拉伸八向锚点缩放以及旋转调整，亦可二次更改其颜色、线宽及填充度。

- **💾 便捷的双重保存交互**：
  - **左键单击保存**：一键静默自动保存图片至您的默认保存路径（以 `screenshot_yyyyMMdd_HHmmss.png` 格式命名），不弹窗打扰，保存进度展示于状态栏。
  - **右键单击保存**：弹出系统的“另存为”对话框，供您手动选择保存格式（PNG/JPG）和目标目录。

- **📌 置顶贴图功能**：
  - 点击“贴图”按钮可将截图以无边框窗口置顶固定在桌面任意位置，可随意拖拽，适合多屏或多文档比对。
  - 贴图工具栏采用暗色微调设计，在白色截图背景下依然拥有极高对比度，方便操作。

- **🔍 屏幕像素取色器**：
  - 在进入区域截屏界面时，鼠标懸停在任意位置后**单击右键**，可即时显示当前像素点的 **RGB 值** 与 **HEX 十六进制颜色码**，点击即可快速复制。

## 🛠️ 构建与部署

本程序采用扁平化目录设计，编译产物直接输出到 `QuickShot\bin\` 下。

### 运行环境
- Windows 10 / 11
- .NET Framework 4.8 或以上

### 使用 MSBuild 进行编译
在项目根目录下打开 PowerShell 执行以下命令：
```powershell
C:\Windows\Microsoft.NET\Framework\v4.0.30319\MSBuild.exe QuickShot\QuickShot.csproj /t:rebuild /p:Configuration=Debug
```
编译成功后，可执行文件将生成在：`QuickShot\bin\QuickShot.exe`

## ⚙️ 全局配置参数

运行后在主界面或托盘右键进入“设置”面板，可以自定义：
1. **常规行为**：随 Windows 开机启动、截图后自动复制到剪贴板、自动保存到默认路径。
2. **默认路径**：截图一键自动保存的目标文件夹（默认指向用户桌面）。
3. **快捷键自定义**：选中输入框直接按下所需组合键即可，按 `ESC` 或 `Backspace` 可清除快捷键（设为无）。
4. **编辑参数**：文本标注默认字号（10px - 48px）、打码马赛克大小、画笔默认填充色透明度。
